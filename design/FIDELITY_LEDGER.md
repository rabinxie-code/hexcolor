# Concept-to-build fidelity ledger

The accepted concepts are `overview.png`, `samples.png`, and `scale.png`. The
implementation was captured in Chromium at 1536 × 1024 after the full
interaction suite passed.

1. **Global shell — matched.** HX lockup, five centered navigation items,
   cobalt active underline, right-side data-scope control, and hairline header
   division all follow the concepts.
2. **Decision hierarchy — matched.** The overview keeps the same outcome-first
   headline, three-column metric strip, open comparison table, and blue selected
   row. Placeholder values were replaced with the benchmark payload.
3. **Route evidence — matched.** The segmented route bar, four-key explanation,
   measured swatch ruler, percent switch, and lower action rail retain the
   concept topology. The actual ruler uses sampled outputs rather than the
   concept's decorative gradient.
4. **Sample comparison — matched and extended.** Filters, horizontally scrollable
   seven-method matrix, radio selection, full-width primary swatches, top-three
   palettes, detail rail, and pagination follow the sample concept. Real S3 crops
   replace the illustrative mock images; mobile stacks all seven method results.
5. **Scale decision — matched.** The 100B equation, eight-row method/audit table, five-node
   pipeline, rejected neural branch, evidence rail, and Go band match the scale
   concept. A fourth evidence cell for the original CPU run was added because
   it materially changes the decision. The accepted concept's 90-day placeholder
   was intentionally replaced by switchable 3 / 7 / 15-day targets, with required
   and 1.5× provisioned throughput shown separately. A compact decode-once capacity
   rail was also added to distinguish production image-level sizing from the
   deliberately pessimistic per-crop CPU-equivalent benchmark.
6. **Visual tokens — matched.** The build uses a near-white canvas, charcoal
   type, cobalt `#075ff7`, 1 px neutral rules, square controls, restrained
   radii, monospace numeric fields, and no card-grid treatment.
7. **Responsive behavior — intentionally extended.** At 390 × 844, the global
   navigation becomes a compact horizontal rail and each sample crop stacks all
   seven method results. The desktop concepts did not prescribe mobile layout.
8. **Evidence additions — intentional.** The conclusion-boundary note, six source
   audit cards, seven unified benchmark methods, original runtime audit, source
   links, and footer provenance are additional audit surfaces; they do not alter
   the concept's primary hierarchy.

No decorative concept asset was shipped in the product. The concepts served as
visual references; all product visuals are CSS, SVG, benchmark data, or sampled
dataset crops.
